# AuctionApp – Kalle Lindberg

Fullstack auction site built for *Inlämningsuppgift 2*.

## Tech stack

- **Backend:** ASP.NET Core Web API, Entity Framework Core, SQL Server, JWT authentication
- **Frontend:** React (Vite), React Router, Context API

## Project structure

```
AuctionApp_KalleLinberg/
├── backend/    ASP.NET Core Web API
└── frontend/   React + Vite client
```

## Getting started

### Backend

```bash
cd backend
dotnet ef database update
dotnet run
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
